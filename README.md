## ⚡ Sobre o Projeto & Metodologia

Este site foi concebido e programado sob o paradigma de **Vibe Coding** — uma abordagem ágil e moderna de engenharia de software onde a ideação, arquitetura de informação e codificação são conduzidas em parceria estratégica com Inteligência Artificial, priorizando clareza, design refinado e foco absoluto na experiência do usuário.

A proposta é transformar um currículo tradicional em uma experiência digital atraente para recrutadores, gestores e parceiros da área de **Estratégia e Ciência de Dados**.

---

## 🛠️ Tecnologias & Ferramentas Utilizadas

| Ferramenta / Tecnologia | Função no Projeto |
| :--- | :--- |
| **HTML5 Semântico** | Arquitetura de informação limpa, acessível e otimizada para SEO. |
| **CSS3 Moderno** | Estilização em **Bento Grid**, efeitos de **Glassmorphism**, microinterações e variáveis nativas. |
| **JavaScript (Vanilla)** | Alternância dinâmica de tema (**Modo Claro / Modo Escuro**) com persistência em `localStorage`. |
| **Lucide Icons & SVG** | Ícones vetoriais leves e consistentes para cada seção e canal de contato. |
| **Paleta Coolors** | Harmonia visual rigorosamente baseada em 5 tons selecionados: `#13293D`, `#006494`, `#247BA0`, `#1B98E0`, `#E8F1F2`. |
| **GitHub Pages** | Hospedagem estática com carregamento ultrarrápido e disponibilidade contínua. |

## 🚀 Como Executar Localmente

Como o projeto é construído em tecnologia web nativa (zero dependências de compilação ou instalação pesada), basta:

1. Clonar este repositório:
   ```bash
   git clone https://github.com/Pedrao0223/curriculo.git
   ```
2. Acessar a pasta:
   ```bash
   cd curriculo
   ```
3. Abrir o arquivo `index.html` em qualquer navegador (dando dois cliques ou usando a extensão Live Server).
